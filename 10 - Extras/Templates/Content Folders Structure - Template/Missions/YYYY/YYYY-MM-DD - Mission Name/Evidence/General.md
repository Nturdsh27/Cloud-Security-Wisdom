# Mission Evidence

## Purpose

The sanitized material that supports the mission record: the queries we ran, the outputs we got and the screenshots that prove the point.

## What This Folder Contains

- Queries, commands and scripts used, in fenced code blocks with placeholders instead of real identifiers.
- Summarized outputs and result tables.
- Redacted screenshots and exports, stored in the root `Attachments` folder and embedded from here.

## Good To Know

> **Nothing raw goes here.** Raw logs, full exports and unredacted screenshots are the single most common way sensitive data leaks into a knowledge base. Summarize first, redact second, commit third.
