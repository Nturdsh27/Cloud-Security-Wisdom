# Mission Findings

## Purpose

The individual findings produced by this mission, one page each.

## What This Folder Contains

- One page per finding: what it is, where it was found, severity, impact, reproduction, recommendation, status.
- Use a single `Findings.md` table instead of this folder when there are only one or two trivial findings.

## Naming

`<Severity> - <Short Finding Title>.md`, for example `High - Public S3 Bucket With Audit Exports.md`.

## Good To Know

Describe the finding so it can be understood and fixed, not so it can be reused as an exploit. Redact identifiers.
