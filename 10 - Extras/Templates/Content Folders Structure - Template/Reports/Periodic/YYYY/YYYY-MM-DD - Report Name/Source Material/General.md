# Report Source Material

## Purpose

The sanitized data and references the report is built on, so its conclusions can be checked later.

## What This Folder Contains

- Queries, scripts and methodology used to produce the numbers.
- Summarized datasets, preferably as Markdown tables or small committed CSVs.
- References to the missions, studies and tickets behind the report.

## Good To Know

Same rule as mission evidence: summarized and redacted only. Never raw exports.
