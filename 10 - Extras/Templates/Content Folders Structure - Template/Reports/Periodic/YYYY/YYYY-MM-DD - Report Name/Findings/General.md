# Report Findings

## Purpose

The individual findings of this report, one page each.

## What This Folder Contains

- One page per finding: description, severity, evidence, impact, recommendation, owner, status.

## Naming

`<Severity> - <Short Finding Title>.md`.

## Good To Know

Track status here rather than in a separate tracker copy, so the report and reality do not drift apart.
