# Architecture Diagrams

## Purpose

The visual representations of this system.

## What This Folder Contains

- Mermaid diagrams, embedded directly in Markdown pages.
- Excalidraw and draw.io files, for diagrams too complex for text.
- A written explanation next to every diagram.

## Naming

`<What It Shows>.md`, for example `Log Ingestion Path.md`.

## Good To Know

If a diagram has not been updated since the system changed, it is misinformation. Delete it or fix it.
