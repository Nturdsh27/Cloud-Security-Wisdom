# Presentation Deck

## Purpose

The slides themselves.

## What This Folder Contains

- The source deck (`.pptx`, Google Slides export, or Markdown slides).
- A PDF export, so the deck can be previewed inside Obsidian without Office.

## Good To Know

Keep one version. If the deck was presented twice with changes, create a second presentation folder for the second date.
