# Presentations

## Purpose

Everything that was presented to an audience: knowledge sharing sessions, debriefs, training and reviews.

## What This Folder Contains

- One folder per year, and inside it one folder per presentation.
- Each presentation folder holds a Markdown summary page plus the deck itself.

## Structure

```text
Presentations/
+-- General.md
+-- YYYY/
    +-- General.md
    +-- YYYY-MM-DD - Topic/
        +-- Presentation.md  # topic, audience, takeaways - start here
        +-- Deck/            # the deck: .pptx / .pdf / Markdown slides
        +-- Demo/            # demo scripts, commands, recordings
```

## Naming

- Year folder: `2026`.
- Presentation folder: `YYYY-MM-DD - Topic`, where the date is when it was **presented**.
- The summary page inside is always `Presentation.md`.

## Good To Know

- **A deck is not knowledge.** `Presentation.md` carries the actual content: topic, audience, presenter, date and the key takeaways in text, so it is searchable. The deck is an attachment.
- For internal sessions, consider writing the slides in Markdown with the **Advanced Slides** plugin — then the deck *is* the page.
- Check the deck for notes, hidden slides and metadata before committing it.
