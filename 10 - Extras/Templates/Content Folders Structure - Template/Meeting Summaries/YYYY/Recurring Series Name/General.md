# Recurring Series Name

## Purpose

A recurring meeting that happens on a fixed cadence, kept together so the thread can be followed over time.

## What This Folder Contains

- One page per occurrence, named `YYYY-MM-DD - Subject`.
- A standing agenda, if the series has one.
- The list of open action items carried across occurrences.

## Good To Know

Rename this folder to the actual series name. Create a series folder only when the meeting repeats - a one-off goes directly in the year folder.
