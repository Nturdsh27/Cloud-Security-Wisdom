# Project Studies

## Purpose

Research, evaluations and proofs of concept produced specifically for this project.

## What This Folder Contains

- Tool and service evaluations with criteria and results.
- Technical deep dives required to make a project decision.
- Proofs of concept: method, results, conclusion.
- Dead ends and rejected options, with the reason for rejection.

## Good To Know

If a study turns out to be useful beyond this project, promote it to `6 - Studies - Department Level` and leave a link here.

## Structure

This folder follows the standard layout defined in `10 - Extras/Templates/Content Folders Structure - Template`. Copy the skeleton from there — do not invent a layout.

```text
<Folder>/
+-- General.md
+-- Study Subject/
    +-- Study.md         # question, method, conclusion - start here
    +-- Experiments/     # what was actually tried, and what happened
    +-- References/      # external sources, papers, vendor docs
```
