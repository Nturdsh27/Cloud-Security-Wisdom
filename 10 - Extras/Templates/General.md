# Templates

## Purpose

The canonical structures and boilerplate used across the repository, so that every team organizes knowledge the same way.

## What This Folder Contains

- `Team Organization of Knowledge - Tempalte` — the full folder skeleton every team folder must follow.
- `Content Folders Structure - Template` — the internal layout of the six recurring content folders: Missions, Reports, Studies, Presentations, Architectures and Meeting Summaries.
- `Document Templates` — one ready-to-copy skeleton per document type, with the properties block and `Related Files` pre-filled.

## Good To Know

Do not improvise a new structure. If the template is missing something you need, change the **template** in its own Pull Request so every team benefits.

Three levels of template, used together:

| Template | Answers |
| --- | --- |
| `Team Organization of Knowledge - Tempalte` | How is a **team folder** laid out? |
| `Content Folders Structure - Template` | How is a **content folder** (Missions, Reports, …) laid out inside it? |
| `Document Templates` | What does a single **document** look like? |

- Read this page first — it is the index and the "why" of this folder.
