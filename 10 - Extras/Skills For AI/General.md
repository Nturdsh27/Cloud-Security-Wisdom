# Skills For AI

## Purpose

Instructions, prompts and skill files that help AI assistants work correctly inside this vault — formatting, properties, conventions and folder placement.

## What This Folder Contains

- Skill and instruction files describing repository conventions to an assistant.
- Reusable prompts for drafting missions, studies, meeting summaries and diagrams.
- Guidance on what an assistant must never do here (invent facts, write secrets, bypass the PR flow).
