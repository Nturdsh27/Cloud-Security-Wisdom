# Attachments

## Purpose

The single, vault-wide location where all pasted images and attached files are stored automatically by Obsidian.

## What This Folder Contains

- Screenshots and images pasted into any note.
- Diagram source files (Excalidraw / draw.io) where not stored next to their page.
- Office / Google exports (`.docx`, `.pptx`, `.xlsx`, `.csv`, `.pdf`) linked from pages.

## Good To Know

Configure Obsidian once: **Settings → Files and links → Default location for new attachments → In the folder specified below → `Attachments`**. From then on, pasting an image (`Ctrl+V`) stores the file here automatically and inserts an `![[image.png]]` link in your note.

Rules:
- Give files meaningful names — rename `Pasted image 20261111.png` to something a human can search for.
- Never store anything sensitive here: screenshots leak more than people expect (URLs, account IDs, tokens, customer names). Crop and redact first.
- Deleting a page does not delete its attachments. Clean up orphans when you remove content.
