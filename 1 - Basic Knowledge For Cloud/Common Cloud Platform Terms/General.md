# Common Cloud Platform Terms

## Purpose

A shared dictionary for cloud terminology, including how AWS, Azure and GCP name the same underlying concept differently.

## What This Folder Contains

- Identity and access: accounts, tenants, projects, roles, policies, principals.
- Networking: VPC / VNet, subnets, peering, private endpoints, egress controls.
- Compute and containers: instances, serverless, managed Kubernetes.
- Storage and data: object storage, managed databases, encryption at rest.
- Logging, monitoring and audit trails per provider.
- Side-by-side translation tables between providers.
