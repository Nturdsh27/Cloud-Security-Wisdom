# CI-CD

## Purpose

Explains how continuous integration and delivery work, and where the security risks live in a modern pipeline.

## What This Folder Contains

- Core concepts: build, test, artifact, release, deploy, environments.
- Pipeline platforms we encounter (GitHub Actions, GitLab CI, Jenkins, Azure DevOps, etc.).
- Secrets handling in pipelines, OIDC / federated identity to cloud providers.
- Supply-chain risks: dependency poisoning, compromised runners, artifact tampering.
- Guardrails: branch protection, required checks, signed artifacts, SBOM.
