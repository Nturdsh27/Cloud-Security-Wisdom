# 1 - Basic Knowledge For Cloud

## Purpose

The shared technical foundation everyone in the department is expected to know. If a concept is assumed by a mission, study or research note, its explanation should live here.

## What This Folder Contains

- `CI-CD` — pipelines, build and deployment concepts, pipeline and supply-chain security.
- `Common Cloud Platform Terms` — the shared vocabulary across AWS / Azure / GCP.
- `GitHub` — repositories, branching, Actions, permissions, secrets and their security implications.
- Any other cross-provider foundation topic that more than one team needs.

## Good To Know

Write for someone who has never seen the topic. Depth and edge cases belong in team folders or studies — this folder is about building a common baseline.
