# Project Tasks

## Purpose

The individual missions and work items that make up this project.

## What This Folder Contains

- One page per task / mission, named after the task.
- Each page: goal, scope, owner, status, what was done, findings, outcome.

## Good To Know

A task page is a mission record at the smallest scope. Keep it concrete enough that someone could repeat the work from the page alone.
