# Project Name

## Purpose

The home of a single project. Everything produced for this project lives here, so that a newcomer can understand it end to end without asking anyone.

## What This Folder Contains

- `Project Description.md` — what the project is, why it exists, scope, stakeholders and status.
- `Architectures` — diagrams and design documents for this project.
- `Meeting Summaries` — decisions and action items from project meetings.
- `Presentations` — decks presented about this project.
- `Studies` — research and evaluations done for this project.
- `Tasks` — the individual missions and work items that make up the project.

## Good To Know

Rename this folder to the actual project name when you copy the skeleton, and update the title property in every file inside it.

## How To Use It

- Read this page first — it is the index and the "why" of this folder.
- Keep the **Contents** table above current — it is how people navigate this folder.
- Every file in this folder must start with the standard properties block followed by a `Related Files` section (see the repo [[README]]).
- In `author` write your full name, your username (the part of your organizational mail between the `xd.` and the `@`) or your initials — whichever you prefer, used consistently.
