# Cloud Security AWS - Projects

## Purpose

All ongoing and completed projects of the **Cloud Security AWS** team. A project is long-lived work with its own scope, stakeholders and deliverables — as opposed to a single mission.

## What This Folder Contains

- One folder per project, named after the project.
- Each project folder follows the standard structure: `Project Description.md`, `Architectures`, `Meeting Summaries`, `Presentations`, `Studies`, `Tasks`.

## Good To Know

Copy the project skeleton from `10 - Extras/Templates/Team Organization of Knowledge - Tempalte/Projects/Project Name` when starting a new project. Do not invent a different layout.
